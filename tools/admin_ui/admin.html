Вход в Мастерскую

Закрытый рабочий стол для добавления HTML-тренажёров, досок уроков и выдачи QR-кодов.

Локально пароль хранится в файле .admin_secret (показывается при запуске start_catalog_server.bat). В облаке задаётся переменной TUTOR_ADMIN_PASSWORD.

Перетащите готовый файл .html — название, класс и наличие звука определятся сами.
